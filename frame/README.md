# 荣休礼相框端界面工程

独立运行 `npm ci && npm run dev`，访问 `http://localhost:5192/`；执行 `npm run build` 可检查类型并生成 `dist/`。

`src/App.tsx` 管理相框独立入口与视图；`src/v6/Activation.tsx` 展示绑定前品牌页与两种绑定方式；`Frame.tsx` 负责七章播放器、照片编排、祝福信、声音与新心意；`BlockCard.tsx` 是播放器使用的内容详情卡。此工程不包含共创或统筹整页。

目前是浏览器相框原型，设备绑定、二维码、验证码、内容包与通知均未接生产服务。入口为了可查看界面预置荣休素材和信件，不能将这种预置方式用于真实设备；正式实现需读取服务端锁定的内容包及设备授权。需求见 [相框 PRD](../docs/PRD/04_荣休礼相框与仪式端PRD.md)。绑定完成前的相框画面不显示受礼者资料。
