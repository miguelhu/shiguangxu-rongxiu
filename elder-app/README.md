# 拾光叙 · 长者 App 首版演示

独立移动网页原型，面向长者验证三条主流程；未接入账号、服务器、亲友关系和真实发送服务。现有小程序、展示链路、相框不受影响。

## 运行

```sh
npm install
npm run dev
npm run build
```

默认地址 http://localhost:5230/ 。使用真机麦克风需要 HTTPS（localhost 除外）。

## 页面和交互

- 四个固定底栏：拾光碎片、发日常、小叙、我的。我的保留陈明远头像、姓名和已保存碎片入口。默认直接进入碎片上传，无展示首页、个人介绍、统计或荣休纪念浏览。我的页面提供碎片、日常记录和亲友入口。
- 拾光碎片：选照片（最多3张，单张20MB）→ 说话或写字 → 直接保存。录音最多60秒，可回听及删除。语音识别受浏览器支持限制；失败时保留录音。识别文字提到预设标签时选中标签，识别出的标签可点选删除，不展示额外标签表单。
- 发日常：选照片／调用设备拍照 → 说话或写字 → 多选亲友 → 预览确认。演示只保存记录，不实际发送。两种流程草稿在本次会话中独立保留。
- 本地记录：IndexedDB 保存照片 Blob、录音、文字、标签、收件人及时间；刷新后可查看。清除浏览器数据会清除记录。未提交草稿不保证关闭后恢复。
- 小叙：微信式对话，提供操作说明和直达入口。目前是规则式使用指南，不是已连接的AI模型；语音消息可录制回听，尚未接通真实模型对话和来信通知。正式接入来信后只提醒“有新来信”，由用户主动打开内容，不主动朗读或铺开私密内容。

## 长者界面约定

复用小程序陈明远老师案例：陈晓禾（女儿）、周宁（同事）、林悦（学生），照片来自同一案例。暖白背景、棕色主按钮，正文约20–21px，标题24–30px；主要按钮至少66px高，避免只用图标。打字按需打开；识别到标签后才显示；小叙入口、页头及消息头像统一使用既有小男孩。一步一个明确动作；录音无需长按，说完再次点击停止；本机保存直接完成，向亲友发送前保留收件人和内容确认。无假电量／状态栏，无自动弹出的小叙。

## 下一阶段

账号和联系人授权、云端上传重试、设备间同步、服务器语音识别与可确认标签建议、真实发送状态与防重复、来信提醒和手动查看入口。接入生成式小叙时不得自动替长者发送、删除或公开内容。原生相机体验、系统文字放大及真机语音识别仍需实机验证。

## 本轮验证

TypeScript及生产构建；移动端照片上传、实际MediaRecorder流程（浏览器模拟音源）、标签编辑、确认保存、多人选择、演示发送、刷新后读取两类记录、对话帮助；360/390/500px宽度检查。真机相机与麦克风未实测。

### 小叙输入栏

默认按住说话，松开发送，上滑65px取消；左侧键盘可切换文字。录音不足0.6秒不发送，最长60秒；切换页面、窗口失焦或触摸中断时取消。权限请求期间松手不会开始录音。保留真实录音供回听，浏览器支持语音识别时可用识别文字触发使用指南；未识别时不假装理解音频，提示改用文字或常用问题。已用浏览器模拟麦克风验证按住、松开发送、上滑取消和文字切换，真机权限与识别仍需实测。

### 我的亲友

家人视图借鉴 photoframe/src/pages/MemberFamilyTreePage.tsx 的头像节点与亲属连线，移动端展示四代10人的演示家谱；除陈老师与陈晓禾外均为新增演示亲属，不绑定真实账号。亲友视图展示周宁、林悦、魏成、陆航。账号标识使用 miniapp/src/v6/content.json 中对应的 userId；不代表已连接真实账号服务。备注与账号身份分离，备注仅本地保存。人物详情可直接发日常，收件人按稳定账号ID选择，保存记录同时包含recipientIds和当时姓名。
