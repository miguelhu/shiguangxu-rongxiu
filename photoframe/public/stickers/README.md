## 裁剪版说明
- 本版已对所有贴纸做统一规则的留白裁剪。
- 裁剪规则：先检测贴纸主体边界，再按固定 1:1 比例输出，并保留约 4% 的安全留白。
- 目标：减少大面积空白背景，同时保持整体风格和边缘安全距离。
