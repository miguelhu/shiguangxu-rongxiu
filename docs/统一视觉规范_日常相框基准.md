# 拾光叙统一视觉规范

以日常相框的暖白面板、照片主视觉和柔和卡片为基准，贯穿展示链路、共创者小程序、统筹者小程序与仪式播放。页面路由、角色权限、表单数据、排序和投稿行为保持原有规则。

## 颜色与材质

| 用途 | 颜色 / 规则 |
| --- | --- |
| 页面背景 | `#fbf3eb` 暖白 |
| 卡片 | `#fffaf4`，按场景使用轻微透明度 |
| 主要正文 | `#2f2a24` 深棕黑 |
| 主操作 | `#72543d` 暖棕，暖白文字 |
| 次操作 / 选中底色 | `#fbe8d5` 浅杏，深棕文字 |
| 分隔与描边 | `#e8d9c8` |
| 照片播放衬底 | `#352d26`，让照片本身决定画面色彩 |

旧版绿色不再作为大面积背景、普通文字或主按钮的默认色。成功、警告、错误仍应以文字和图标表达，不单靠颜色区分。

## 字体与层级

采用与相框一致的无衬线字体栈，优先 Nunito Sans / 思源黑体，回退到系统中文字体。不依赖外部字体请求。标题中等加粗，正文常规字重。原有 `--serif` 是兼容变量名，现指向统一字体。

手机保留原有响应式尺寸与至少约44px的主要触控目标。仪式画面采用容器宽度单位调整正文和辅助文字，避免桌面截图字号直接套在小屏上。相框的大字不直接搬到小程序表单。

## 页面应用

- 展示链路：暖白背景、浅杏选中状态、深棕标题；角色切换、步骤导航和多端对照遵守同一套配色。
- 小程序：共创、统筹、账户和提醒页面使用暖白卡片；紧凑输入框、小叙入口及交互保持一致。
- 仪式封面：保留受礼者照片，使用中性深棕渐变保证白色文案清晰。
- 人物印象、祝福汇集与结束：暖白渐变底与浅色卡片。
- 照片轮播：中性深色底，保留照片布局、排序、轮转和动画。
- 故事与AI祝福信：暖白阅读面板、深棕文字，保留查看全文和信件功能。
- 日常相框：作为视觉基准，沿用既有界面与入口。

## 代码位置

三个独立工程的 `src/v6/frame-theme.css` 保持一致。历史样式中的绿色色值已迁移为保留原亮度的暖中性色；新页面应优先复用主题变量，不再追加独立绿色配色。`--green` 为兼容既有代码保留的主操作变量名。

验收关注：手机无横向溢出；仪式七个章节均可导航；照片上的文字有遮罩保护；AI祝福信可阅读；减少动态效果偏好关闭装饰性动画；主题调整不改变内容和业务行为。
