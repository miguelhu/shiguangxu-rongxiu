# 长者App实现差距

记录基于2026-10-21主分支规格，2026-10-27整理；不是本轮重新运行产品测试的结果。当前要求见[长者App PRD](../../PRD/各端/长者App.md)。

## 当前实现与正式版差距

| 能力 | 当前代码事实 | 正式开发剩余 |
| --- | --- | --- |
| 导航、三侧栏、六卡 | 已有可交互网页实现 | 原生适配与真机可访问性 |
| 小叙 | 规则／示例对话、浏览器转写与朗读 | 真正上下文Agent、工具权限、全页面语音 |
| 保存与我的拾光 | IndexedDB本地内容、分类、媒体与文章 | 账号空间、云存储、详情编辑／删除、检索与同步 |
| 历史 | 当前页面会话与示例列表 | 账号级云端历史、跨设备恢复、删除治理 |
| 日常与DM | 保存演示记录，不真实投递；部分旧DM仍有预览确认 | 统一按第9／10节直接发送语义，真实逐人投递回执 |
| 提醒 | 本地规则CRUD、有限文本提取；当前完成标记仍是规则级 | occurrence执行项、服务端调度、通知、相框通、全语音修改 |
| 亲友邀请 | 同源本地状态、演示邀请码、可编码二维码 | 账号鉴权、服务端token、跨手机真实申请、审批和撤销 |
| 家谱 | 固定案例树、浏览与名单、部分备注 | 真实树、语音候选确认、编辑事务、账号认领 |
| 微信与相框 | 入口与未接通反馈 | 登录SDK、绑定服务、设备授权、完整同步 |
| 相框素材 | 独立工程展示，非统一云库 | 使用公共对象和增量协议接入，不复制本地数组 |

“不存在帮我看看入口”“没有添加提醒按钮”“无回忆进度条”“无发过日常独立页”为当前要求；旧代码兼容组件不可因此重新出现在正式导航。
