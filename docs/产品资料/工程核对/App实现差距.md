# App实现核对记录

以下为历史时点的原型观察，非本轮重新运行测试的报告。当前开发以[长者App PRD](../../PRD/各端/长者App.md)为准，旧四底栏实现不再是目标。

## 2026-10-13 V3核对

| 能力 | 当前状态 | 正式开发缺口 |
| --- | --- | --- |
| 连续聊天、记录保存、媒体上传、我的 | Web原型可交互；IndexedDB本地存储 | 正式账号、云端与持久化会话 |
| 圆形相机入口、取景、镜头切换、拍照、亲友确认 | Web原型可点击；发送仅演示 | 拍摄全流程语音动作、原生权限和相册 |
| 按住说话、转写、朗读 | 浏览器能力与规则Mock，非真实通用Agent | 流式ASR、NLU、执行器、连续监听与真机验证 |
| 语音选择任意选项／导航／设置 | 未全面接入 | 统一动作注册表、页面状态和编号消歧 |
| 改写、找照片、问候建议、姓名澄清 | app-cases固定案例交互演示 | 真实模型、检索、置信度及权限执行 |
| 真实发送与回执 | 未接通 | 消息服务、稳定身份、送达与重试 |

展示站当前8例：老照片慢慢聊、近况送给女儿、记不清也能留下、聊着换件事、口述整理、找照片、问候措辞、听错名字确认。案例页的步骤切换不等于产品状态机已实现；静态分支不等于真实Agent理解。正式 App 不展示固定案例人物和解释性讲解。

已有7项Agent回归测试及相机模拟设备流程验证仅覆盖已实现原型，不能作为上述全语音12项验收通过依据。上线必须补充真实摄像头、麦克风、方言、屏幕阅读器、系统权限与后台中断测试。

## 2026-10-10 V1核对（历史）

| 能力 | 当前 elder-app 原型 | 正式产品剩余 |
| --- | --- | --- |
| 四底栏及长者布局 | 已实现 | 真机与无障碍完整验收 |
| 照片、录音、文字 | 浏览器真实文件与MediaRecorder | 原生设备集成、上传恢复 |
| 保存记录 | IndexedDB本机 | 云存储、跨端同步、版本恢复 |
| 日常发送 | 本机模拟记录、稳定账号ID | 真实授权、发送与回执 |
| 个人资料、字号、备注 | localStorage | 服务端和账号隔离 |
| 小叙按住说话 | 松开发送／上滑取消，浏览器识别 | 稳定语音服务、工具权限 |
| 小叙回答 | 规则式使用指南 | 模型对话与确认执行 |
| 家谱树 | 四代10人示例、名单、详情 | 服务端真实树、多人编辑 |
| 小叙对话加家人 | 本PRD定义完整流程，当前未实现 | 提取、澄清、确认、事务写入、撤销 |
| 提醒与新来信 | 未接通 | 通知服务、免打扰、主动查看 |
| 正式账号／隐私操作 | 未接通 | 登录、退出、注销、数据导出 |

当前演示只能使用虚构案例与测试素材。前端上的“未实际发送”等说明在接通正式能力后替换为真实状态，不能在能力缺失时直接删字伪装上线。
