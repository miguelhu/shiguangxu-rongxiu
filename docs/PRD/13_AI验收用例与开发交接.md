# AI 验收用例与开发交接

版本：2026-10-14 · 本文件为待执行验收方案，不是测试通过报告。能力定义见[10](10_跨端AI能力完整PRD_V1.md)，页面覆盖见[11](11_跨端AI页面与能力映射.md)，生产门禁见[12](12_AI产品决策回传与差异清单.md)。

## 1. 验收层次与责任

- 产品／内容：事实、归属、语气、四风格区分、页面可读性。
- 算法：受控输入输出、缺失和冲突、Prompt版本、空结果与真实样本评测。
- 后端：来源授权、revision、hash、失效、幂等、删除、审计与真实执行回执。
- 前端：标准例句、适用动作、候选采用／撤销、加载取消、权限错误、语音与点击等价。
- 测试：逐能力用例、跨端状态、真实设备和服务链路；不得用固定例句、mock成功代替验收。

## 2. 逐能力最小用例

每行至少执行一个正常样本和所列异常样本，保留输入来源、期望、实际输出、模型／Prompt版本、结果与问题单。涉及“关闭”能力先测关闭门禁；专项通过后再测能力效果。

| --- | --- | --- | --- |
| AT-01 | AI-01 | “他做事很认真”；另测空白 | 建议词不添加获奖／领导身份；选择才写入，空白不捏造个性 |

## 3. 跨端与版本用例

| 用例 | 流程 | 通过标准 |
| --- | --- | --- |
| E2E-01 | 小程序投稿→统筹审核→AI-05→确认→锁版→相框播放 | 所有输出有正确源与revision；相框消费同一成品，不重复生成；提交与发布分开 |
| E2E-02 | 模型运行中作者撤回源或撤销用途 | 返回候选不能采用；总信确认失效；索引、摘要和缓存读路径即时阻断 |
| E2E-03 | 统筹A请求后移交给B，再收到结果 | A不能采用／锁版；B在现有权限下重新评估；不能用旧角色token越权 |
| E2E-04 | App保存本人记忆→相框检索→分享给绑定亲友 | 明确保存可直接成功；检索受权限；外发另有收件人＋内容确认和回执 |
| E2E-05 | 手机点发送后超时重试、同时语音说发送 | 同一幂等任务只投递一次；未知结果显示待确认，不假报失败后重复投递 |
| E2E-06 | 多账号切换、不同项目、现场设备 | 会话、任务、候选、来源和索引隔离；现场设备不能访问健康／私人库 |
| E2E-07 | 原文编辑后迟到AI响应、连续生成两次 | 不覆盖较新版本，不把旧结果标成最新；用户可查看或丢弃旧候选 |
| E2E-08 | 选择四风格分别点／语音执行 | 枚举一致，事实相同；静态范例不替换真实输入；不支持风格的页面不展示选择 |
| E2E-09 | App每个可点击页面动作逐项语音执行 | 同前置条件、权限和结果；系统相机／媒体权限必须真实验证，非只测聊天页 |
| E2E-10 | 前台连续收听→锁屏／后台／撤麦克风／换账号 | 立即停止收听；恢复不自动偷偷开启；插话停止TTS |
| E2E-11 | 生成超时、限流、空输出、无provider、离线 | 保留原文；提示真实状态，支持合适重试；无固定成功稿和假保存／假发送 |
| E2E-12 | 未拆封礼物→日常相册／周报／问答／检索 | 所有旁路不可泄露，正式获准拆封后才按用途进入可访问范围 |
| E2E-13 | 冻结后撤回，离线相框再联网 | 在线先阻断再同步撤销；离线按已定有效期；不得承诺断网立即擦除 |
| E2E-14 | 超字数故事／说明→精简或分屏 | 保留关键否定、数字、主体和不确定性；无静默截断，用户能看全文 |
| E2E-15 | 清理候选、删除原件、删除账号 | 按冻结后的留存策略执行，验证依赖、索引与第三方删除回执；日志不留全文 |

## 4. 内容评分与事实否决

六维使用1—5分，权重点数为：事实忠实30、任务完成20、情绪适度20、个性保留15、角色授权10、展示适配5。总分公式：`Σ(该维得分 / 5 × 权重点数)`，满分100。

- 出现事实捏造、归属错置、未经授权引用、原声冒充、私密泄漏、假执行成功等严重问题，一票否决，总分不能补偿。
- 合格：总分≥85，事实=5，任务≥4，其余各维≥3，且无否决项。
- 优秀：总分≥95，各维≥4，且无否决项。
- 总分<75不合格；其余未满足合格条件为需修改，不能作为可发布稿。
- 机器筛查只作辅助；事实、归属和授权必须结合源和业务记录核对。人工原文已自然时“无需修改”可以合格。

评分用于内容能力；ASR另测关键实体／否定识别，检索测授权过滤与相关性，Agent测动作正确性及误执行，TTS测音频和可懂度。不能给发送接口一个文案分数来证明成功。

### 已有测试材料能证明什么

原规范40条案例是规则与评测素材，不是40条生产模型通过记录。Dify阶段小结的最新10条预设任务中有4条完整输出、6条空输出，空输出原因尚未定位；不能据此声称质量通过率。已有现象包括诱导式追问、归属错误在高评分下漏检、自然风格最小改写更稳。本版要求保留空输出与失败样本，不能只展示成功稿。

建议首轮评测：完整回跑原40条规范样本；同一原文覆盖四风格与适用动作；加入AT与E2E负例。逐模型／Prompt版本报告完成率、事实错误率、归属错误率、越权率、用户采用率及端到端时延分布。质量门禁是零严重越权／误执行；时延、费用和成功率阈值由AI-D05结合真实服务冻结，不伪造当前指标。
