# 跨端 AI 页面与能力映射

版本：2026-10-14 · 配套[统一能力定义](10_跨端AI能力完整PRD_V1.md)。本表是页面接入清单，不是已实现清单。

## 1. 使用方式

页面键加端前缀：`MP`小程序、`CO`统筹、`FR`相框、`APP`长者App。例如MP.C01与FR.C01不是同一页。统筹是角色工作区，不预设必须另建一个客户端。App V3没有完整稳定页面编号，表中APP名称是本版逻辑键，开发须映射真实路由，不能沿用旧导航假装已有页面。

**G**生成／识别候选；**D**消费已确认结果；**X**业务执行；**T**固定模板；**R**确定性规则；**N**不需要AI。G不表示可以直接写入；X由业务服务完成。每次调用记录统一AI编号、端、页面键、场景与对象版本。

## 5. 长者 App（09为交互主规格，07为业务补充）

**全页面统一底座：AI-11命令转写＋AI-19动作提案＋业务执行器；可朗读反馈复用AI-18。** 下表列额外能力。每个可点击动作都应登记语音意图、参数、前置条件、确认级别、结果和失败回复；没有AI文案需求的页面仍需满足V3语音操作要求。

| 逻辑页面键 | 额外能力 | 关键要求 |
| --- | --- | --- |
| APP.拾光持续对话 | AI-12／13／03 | 命令和叙事分流；保存后不清空会话，明确新记录才另开任务 |
| APP.快捷选项 | R／AI-19 | suggestionSetId、optionId、taskId、stateVersion绑定；“第一个”只指当前有效选项 |
| APP.圆形相机 | 原生相机X | 打开预览、切镜头、倒计时、取消、重拍、采用；无后台偷拍，系统授权不能绕过 |
| APP.相册选择 | 原生媒体X；AI-02仅说明整理 | 自有选择页支持语音，受系统有限照片权限约束；选择照片不是授权读取整个图库 |
| APP.日常编辑 | AI-10／AI-02 | 近况与照片说明按场景复用；不混成私密人生记忆或自动外发 |
| APP.记忆编辑／保存 | AI-03／13／16 | 无最低字数、无强制年份；明确保存本人记录可直接执行，无需一律多一层预览 |
| APP.查找记忆／结果 | AI-17 | 查询当前账号获准记录；匹配片段与出处可打开；不把相似经历说成用户事实 |
| APP.我的／个人档案 | R；AI-19 | 普通资料不需生成；切换账号清空会话权限与未执行提案 |
| APP.家谱／成员详情 | AI-20 | personId与accountId分离；提取→待确认关系，不能因同名或共同子女推断配偶 |
| APP.联系人／收件人选择 | R；AI-19 | 只有真实绑定且可达的联系人可发送；家谱占位成员不能充当渠道账号 |
| APP.发送预览／结果 | X；AI-19 | 收件人＋内容＋渠道确认令牌；任一变化令牌失效；重试同幂等键不重复发 |
| APP.消息／收到的内容 | D；AI-18 | 按现有业务入口呈现；未获权源不能进入摘要和后续问答 |
| APP.设置／权限／退出 | R；AI-19 | 语音可引导或发起已支持设置；系统权限由用户在系统界面决定 |

前台连续收听须明确开启；切后台、锁屏、撤权、换账号即停止。用户插话停止TTS。低置信度先澄清；“好”“嗯”不作为发送、删除、公开授权。上述要求适用于每个原生页面，不能仅在聊天页演示。

## 6. 工程对接示例

同一“顺一顺故事”：MP.C13、FR.M09、APP.记忆编辑均传`capabilityId=AI-03`、`action=smooth`、相同style枚举；分别传各自对象、作者、权限和长度约束。不会因复用模型而共用用户上下文。

同一“口述”：三端都为AI-11，但`variant=dictation`形成待确认转写，`variant=command`进入AI-19；`variant=original_blessing`原音是独立资产。原声播放不是AI-18。

同一“集体信”：CO.L01生成AI-05，FR.C06消费相同成品ID与revision；相框不再发一次生成请求。AI-09改稿后必须重新确认再生成新播放包。

新增页面必须在本表登记：页面键、能力ID／N、模式、来源范围、确认与验收。新页面复用既有语义不另造编号；新增语义经产品评审后追加编号。
