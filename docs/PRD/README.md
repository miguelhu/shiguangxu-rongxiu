## 一条规则只在一处维护

- **总览**：项目状态、角色、授权、通知事件、公共参数与D系列待定事项。
- **各端**：页面、用户动作、异常与本端验收。相框第19节统一定义跨端照片排序与拼图；其他端引用同一结果。
- **AI**：能力语义、内容规范、输入输出、候选与执行边界。相同功能跨端共用AI编号，不共用用户权限和上下文。
- **资料**：保留为什么这样决定、旧稿和实现证据。资料不反向覆盖当前需求；未定事项不能因为出现在问卷答复里就视作批准。

本次按已有有效规则归并冲突；未能从原规格确定的参数继续标“待定”，不替团队虚构决定。核心与增强范围分别写明，“完整PRD”不等于所有功能同时首发，也不代表已实现。

## 后续怎么改

更新规则时直接修改所属主文档，并同步受影响的引用和验收，不再追加一份“补充PRD”或在末尾贴覆盖正文的意见。版本记录由Git保存；值得保留的评审结论放到产品资料。新需求只有形成独立产品范围时才新建主文档。
