## 当前产品已明确的界面

- App顶部为菜单、小叙、消息、圆形相机；不保留底部大加号导航。
- 侧栏为新话题、小叙、我的提醒／我的拾光／我的亲友、历史对话、底部我的；没有帮我看看。
- 首页六张话题卡按两列三行排列，按本人已确认资料和可用功能生成，可换组；不显示段落／章节／小文进度条。
- 提醒由底部讲话或键盘输入创建，没有添加提醒大按钮。
- 我的亲友右上角加好友，家谱在家人标签；我的里没有发过的日常独立入口。
- 我的拾光映射相框库，但不默认轮播、外发或改动冻结仪式。

## 不可混淆的公共规则

1. 四张照片的拼图条件是连续、同作者、同允许时间桶，不是四位作者或照片内四个人。
2. 共创提交完成、统筹礼物完成、设备绑定、正式拆封、日常内容同步是不同事件。
3. accountId、personId、spaceId、deviceId、projectId独立；好友关系、投稿关系和家谱关系独立。
4. 同步入库、轮播展示、发给亲友、加入仪式四种用途分别授权。
5. 本人新拾光、别人投稿原稿、来信收藏、聊天历史不是一个默认共享的内容池。
6. 原型采用本机存储与示例状态，尚未完成真实账号、云库、投递、通知和相框同步；正式验收须使用真实服务与设备。
