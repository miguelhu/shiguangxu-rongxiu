## 组件边界

- HomeNavigation：拾光／我的及当前状态。
- XiaoxuAssistant、WelcomeMessage：小男孩形象、按资料称呼；陈老师案例不使用奶奶称呼。
- ConversationArea：顺序消息、转写／原音频、媒体、朗读。
- ChatComposer：复用语音／文字输入，新增开始录音回调和保存期间禁用。
- UploadTrigger、MediaPreview：图片／拍照／视频／音频上传和展示。
- AgentSuggestion：快捷操作，与自然语言驱动同一意图状态。
- MemoryProgress：语义丰富度，段落／章节／小文；没有字数或百分比门槛。
- MemoryActions：随时保存、确认舍弃。
- AgentHome：上下文、状态转换、亲友选择、分享确认和存储协调。
- model：字段提取的Mock规则、丰富度判断、本地记录写入。

## 状态与转换

welcome → 录音开始后欢迎区收为小头像、加号隐藏 → 语音转写／用户消息 → memory或choice。
welcome → 加号选择内容 → choice（存起来／发出去）。
choice → memory → 收集背景 → 保存 → saved → 再记一段回welcome。
choice／自然语言分享 → share → 选择内容与亲友 → confirm → 保存模拟发送结果 → saved。
进行中 → 暂时舍弃 → 确认弹层 → reset；取消弹层继续原会话。saved内容不被reset删除。
切换「我的」保留未结束会话，录音停止，返回仍可继续。刷新未保存会话暂不持久化，已保存记录从IndexedDB恢复。

## 连续记录

照片、视频、声音可上传，同一记录演示建议最多6份上传文件，每份50MB。文件格式由浏览器支持决定。照片不假装做视觉识别，系统仅确认已接收文件，不猜其中的人。

时间、地点、人物、事件、心情通过对话补充，不作为必填表单。Mock根据关键词与当前提问标记信息，不精确解析亲属身份或相对年份；“退休前一年”保留原话，不凭空转为某年。用户已讲的内容不重复追问。用户表达“不记得”时允许未知并跳过。

进度阶段由信息是否形成背景、事件与主观感受的语义组合驱动。实现中的轨道位置只是三个标签的显示位置，不代表完成率，不限制保存。没有明确情绪时仅复述用户原话；不能凭空说用户开心或难过。

录音本体完整保留，识别失败显示真实状态，可直接存声音，不填入伪造文字。朗读支持单条手动播放与自动开关，录音、切页时停止播放；系统不支持时提示。真实语音服务尚未接入。

## 保存与分享

保存写入原有items表，含照片、音视频、叙述、背景字段、时间和稳定记录ID；同一会话使用同一ID避免连点重复。只有存储事务成功才显示成功；失败保留内容允许重试。

分享与存储不同意图。亲友按既有账号ID预选／多选，确认页显示全部对象与内容。当前仅保存发送演示记录，确认时明确不会实际发出，不制造送达结果。

自然语言“发照片给孙女”触发分享和选照片，但当前案例孙女未关联账号，必须解释不可直接发送并提供已关联联系人选择。不能将孙女映射为女儿以让演示通过。简单语音意图与按钮走相同状态；自由语言理解能力仍是Mock，需正式Agent替换。
