# 我的拾光：分类与文章收藏

- 分类：全部、照片、声音、文章、视频、文字。分类来自实际记录，同一条记录可属于多个分类；全部中只计一次。
- 原有照片、录音与视频沿用现有 IndexedDB 数据，无需迁移；无素材的讲述文字归文字，明确收藏的文章归文章。
- 我的拾光内提供收藏文章入口；小叙上传面板增加文章入口。
- 文章保存标题、正文、作者或来源；支持粘贴正文、UTF-8 TXT 上传（最大1MB，正文最多5万字）。暂不解析 PDF、Word 或网页链接，链接仅作为来源字段保留。
- 标题与正文必填，来源选填；失败保留当前输入，可重试；保存时防重复点击。
- 分类卡片展示日期、标题、来源及摘要，支持展开全文、收起、浏览器语音朗读、停止朗读。离开收藏列表时停止朗读；设备不支持时提示。
- 内容仍存当前浏览器，没有增加云同步或账号服务。首页不堆放存储技术说明，隐私页面保留当前存储范围。
- 验证：文章上传、分类、来源保留、展开、刷新后读取，以及原有Agent与直接发送回归，共10项自动化测试通过。
